# maple-mono-nf-cn-woff2

Maple Mono NF CN 精简 WOFF2 包（**standard**，6 个文件，约 37.13 MB）。

## 字重

| 文件 | weight | style |
|------|--------|-------|
| MapleMono-NF-CN-Regular.woff2 | 400 | normal |
| MapleMono-NF-CN-Italic.woff2 | 400 | italic |
| MapleMono-NF-CN-Medium.woff2 | 500 | normal |
| MapleMono-NF-CN-SemiBold.woff2 | 600 | normal |
| MapleMono-NF-CN-Bold.woff2 | 700 | normal |
| MapleMono-NF-CN-BoldItalic.woff2 | 700 | italic |

## 使用

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/maple-mono-nf-cn-woff2@7.9.0/css/maple-mono-nf-cn.css" />
```

许可证：SIL OFL 1.1。
